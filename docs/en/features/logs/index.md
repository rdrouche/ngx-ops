# Logs in NGX Ops

The logs generated by Nginx are a central element of **NGX Ops**, because they sit at the heart of several features:

- Live log display, which lets you follow requests on your virtual hosts
- Analysis
- WAF
- Periodic summary
- Map
- IP blocklists analysis

To make full use of these logs, you need to configure the [**Nginx Analyzer**](../nginx-analyzer.md) service.

## Centralize logs

To keep logs, search them and correlate them across several servers, NGX Ops can send them to a [log store](log-store.md) through a [shipper](shipper.md). Orders of magnitude are given in [Log store capacity](log-store-capacity.md), and multi-instance browsing in the [Hub](../../hub/index.md).
