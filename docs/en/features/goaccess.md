# GoAccess

[GoAccess](https://goaccess.io/) is an open source web log analyzer that generates detailed statistics from Nginx `access_log` files.

NGX Ops lets you integrate **GoAccess directly into its interface** to get, for one or more virtual hosts, a visit statistics interface without having to deploy and configure a GoAccess container manually.

The goal of this integration is to let those who want it get statistics directly in NGX Ops such as:

* the number of visitors and requests;
* the most viewed pages;
* the most requested files;
* the HTTP codes returned;
* the browsers and systems used;
* User-Agents;
* the visitors' countries of origin;
* referrers;
* bandwidth consumption;
* traffic evolution.

GoAccess works directly from Nginx **`access_log`** files. It therefore does not take part in request processing and does not change how the reverse proxy works.

> **GoAccess and Nginx Analyzer are complementary:** GoAccess is mainly intended for statistical analysis and traffic visualization, while Nginx Analyzer is oriented toward detecting unusual behavior and triggering alerts.

## Start a GoAccess container

To start GoAccess from NGX Ops, go to:

**INTEGRATION → GoAccess**

Then select a VHost in the left panel and click **Start**.

<img src="https://static.rdr-it.com/docs/nginx-dashboard/nginxdash-028-goaccess.png" width="800" />

A configuration window then lets you set the GoAccess container parameters for the selected VHost.

Two options are notably offered:

* **Persistent data**: keeps the data generated by GoAccess between container restarts;
* **GeoIP integration**: enriches the statistics with the geographic information associated with IP addresses.

For GeoIP integration, see the [**GeoIP**](geoip.md) documentation.

Once the configuration is done, click **Start**.

<img src="https://static.rdr-it.com/docs/nginx-dashboard/nginxdash-029-goaccess.png" width="800" />

## Log analysis

Once the container is started, GoAccess begins analyzing the log files associated with the selected VHost.

It uses Nginx `access_log` files to build the different statistics and generate its web interface.

<img src="https://static.rdr-it.com/docs/nginx-dashboard/nginxdash-030-goaccess.png" width="800" />

The interface then lets you view the VHost's different statistics and analyze visitor activity.

<img src="https://static.rdr-it.com/docs/nginx-dashboard/nginxdash-031-goaccess.png" width="800" />

> **Note:** GoAccess analyzes the information present in the Nginx logs. The quality and accuracy of the statistics therefore depend directly on the `access_log` configuration and the logging format used.

<hr />

> **Note:** on high-traffic VHosts, after several weeks of use, the GoAccess container can become quite resource-hungry and use several hundred megabytes of RAM.
>
> To have statistics over a longer period while limiting resource consumption, I am currently considering integrating **AWStats** into NGX Ops.
>
> The goal would notably be to offer a solution better suited to sites generating a large volume of logs and needing long-term statistical history.
